Sensormeter Display — Web-Flasher

Firmware direkt aus dem Browser auf das ESP32-Touchdisplay (Board HW-458B) flashen. Kein Tool-Setup nötig.

⚠ Dieser Browser unterstützt Web Serial nicht. Bitte Chrome, Edge oder Opera am Desktop verwenden (Firefox, Safari, iPhone/iPad funktionieren nicht).

Firmware flashen

Die komplette Sensormeter-Display-Firmware (aktuelle Version). Board per USB anstecken, Button klicken, den seriellen Port wählen — der Rest läuft automatisch.

Nach dem Flashen startet das Gerät die Ersteinrichtung: Auf dem Touchdisplay einen WLAN-Scan ausführen, WLAN wählen und den Schlüssel per Bildschirmtastatur eingeben. Details im Admin-Guide.

Hinweise

  1. Browser: Chrome/Edge/Opera am Desktop (Web Serial nötig).
  2. Treiber: ggf. den USB-UART-Treiber des Boards installieren (CH340 bzw. CP210x).
  3. Auswahl: im Port-Dialog den seriellen Port des Boards wählen.
  4. Bricht die Verbindung ab, BOOT/EN am Board kurz betätigen und erneut versuchen.
